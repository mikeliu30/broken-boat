## 1. 项目概述

复刻参考网站风格，搭建个人技术与生活混合博客"破船之家"。使用 Hugo 静态站点生成器配合 Reimu 主题，部署至 GitHub Pages，支持四种语言，提供可切换背景图和炫酷视觉特效。

**博客基本信息**
- 名称：破船之家
- 副标题：破船不翻，代码相伴，生活不慌
- 简介：一艘载满代码、bug、生活趣事的小船正式启航。在这里，你能看到接地气的代码教程、程序员的日常吐槽，也能发现生活里的小美好。没有高冷的技术说教，只有轻松的分享与交流。代码是我们的伙伴，生活是我们的底色，一起在破船里，解锁技术与生活的双重快乐！
- GitHub：https://github.com/mikeliu30
- 部署地址：https://mikeliu30.github.io

## 4. 多语言支持

- 支持语言：简体中文（zh）、英文（en）、日文（ja）、韩文（ko）
- 默认语言：简体中文
- 语言切换：导航栏右上角按钮，图标 🇨🇳 / 🇺🇸 / 🇯🇵 / 🇰🇷
- 各语言独立翻译导航菜单、侧边栏标签、页脚文字
- 文章内容由作者手动创作对应语言版本，不做自动翻译

**导航菜单翻译对照**

| 功能 | 中文 | 英文 | 日文 | 韩文 |
|------|------|------|------|------|
| 首页 | 首页 | Home | ホーム | 홈 |
| 归档 | 归档 | Archives | アーカイブ | 아카이브 |
| 分类 | 分类 | Categories | カテゴリー | 카테고리 |
| 标签 | 标签 | Tags | タグ | 태그 |
| 关于 | 关于 | About | について | 소개 |
| 友链 | 友链 | Links | リンク | 링크 |

## 5. 背景切换功能

- 背景图由博主提供，存放于 `static/images/bg/` 目录
- 页面右下角固定小按钮，点击循环切换背景
- 使用 `localStorage` 记住访客上次选择，刷新后保持
- 切换时带有淡入淡出过渡动画（CSS transition）

## 6. 视觉特效

### 保留（参考网站原有）
- **Typed.js 打字机**：副标题循环打字动画
- **AOS 滚动动画**：文章卡片进入视口时淡入
- **烟花点击特效**：鼠标点击页面产生烟花爆炸效果

### 新增
- **星空粒子层（Particles.js）**：背景图上叠加动态流动粒子，营造星空感
- **文章卡片 3D 倾斜（VanillaTilt.js）**：鼠标悬停文章卡片时产生立体视差倾斜效果

## 7. 页面结构

### 首页
```
顶部 Banner
  ├── 博客名"破船之家"
  ├── Typed.js 副标题动画
  └── Particles.js 星空粒子层（叠加在背景图上）

导航栏
  ├── 菜单项（首页/归档/分类/标签/关于/友链）
  └── 语言切换按钮（右上角）

主内容区
  ├── 文章列表（卡片布局）
  │   └── 每张卡片：标题 + 摘要 + 日期 + 分类标签 + VanillaTilt 倾斜效果
  └── 分页器

侧边栏
  ├── 个人简介卡片（头像 + GitHub 链接）
  ├── 分类列表
  ├── 标签云
  └── 最新文章

页脚
  └── 版权信息 + GitHub 链接

右下角固定按钮组
  ├── 背景切换按钮
  └── 回到顶部按钮
```

### 文章页
- 标题、日期、分类标签
- Markdown 正文渲染
- 侧边悬浮目录（TOC）
- 代码块一键复制
- 上一篇 / 下一篇导航

### 关于页
- 个人头像
- 博客简介文字（用户提供的完整简介）
- GitHub 链接

---

## 8. 部署流程

1. 代码推送至 `main` 分支
2. GitHub Actions 触发 Hugo 构建
3. 构建产物自动推送至 `gh-pages` 分支
4. GitHub Pages 从 `gh-pages` 分支发布

---

## 9. 内容规划（初始）

博客内容分两大方向：
- **技术**：代码教程、AI 工具、编程笔记、bug 记录
- **生活**：日常吐槽、生活趣事、小美好

建议初始发布 3-5 篇文章（中文），覆盖两个方向，确保博客上线时内容充实。
